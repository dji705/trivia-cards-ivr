# Trivia & Cards IVR

משחק טלפוני בעברית למערכת ימות המשיח, בפריסה ב-Vercel.

## מה כלול
- טריוויה: חמישה סיבובים, ארבע אפשרויות לכל שאלה וניקוד.
- מלחמה נגד בוט: חפיסת 52 קלפים, עד עשרה סיבובים, ללא כסף או הימורים.
- שמירת מצב משחק לפי מספר מתקשר למשך 12 שעות.

## פריסה
1. חברו את המאגר ל-Vercel ופרסו כפרויקט Node.js.
2. הגדירו מאגר Redis של Upstash וחברו את משתני הסביבה:
   - `UPSTASH_REDIS_REST_URL`
   - `UPSTASH_REDIS_REST_TOKEN`
3. הפעילו מחדש את הפריסה.

כתובת ה-API לאחר הפריסה: `https://YOUR-PROJECT.vercel.app/api`

## הגדרת ימות
הגדירו שלוחת API שמפנה לכתובת ה-API. יש להפעיל העברת נתוני זיהוי מתקשר כדי לשמור משחק נפרד לכל שחקן. השרת מחזיר פקודות `read` בפורמט טקסט של ימות.

## מקשים
- 1 — טריוויה / המשך סיבוב במשחק מלחמה
- 2 — מלחמה נגד בוט
- 3 — הוראות
- כוכבית — חזרה לתפריט הראשי ואיפוס המשחק הנוכחי

## הערות
המשחקים הם לבידור בלבד. אין כסף אמיתי, הימורים, פרסים או רכישות.
